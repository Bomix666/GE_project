# GLOBAL EFFECTS — Design System (MASTER)

Единый источник правды для визуальной системы. Код: `src/styles/tokens.css`.
Компоненты ссылаются **только на семантические токены**, не на hex.

## 1. Бренд и соотношение цветов
Чёрный 70–80% · off-white 15–20% · красный 5–10%. Красный — это энергия внутри чёрного:
CTA, активная навигация, прогресс, важные номера, подчёркивания, акценты движения.

| Токен | Значение | Назначение | Контраст |
|---|---|---|---|
| `--bg` | `#050505` | фон страницы | — |
| `--surface-1…4` | `#0a0a0b` … `#252528` | панели, drawer, диалоги | — |
| `--text` | `#f4f2ef` | основной текст | 18.2:1 |
| `--text-2` | off-white 70% | вторичный текст | 8.9:1 |
| `--text-3` | off-white 56% | метки, мета | 5.9:1 |
| `--accent` | `#ec1c23` | цвет из логотипа: линии, точки, прогресс, крупные заголовки | 4.6:1 (крупный) |
| `--accent-fill` | `#d9141b` | заливка кнопок под белым текстом | 5.2:1 |
| `--accent-fill-hover` | `#e3161e` | hover-заливка | 4.8:1 |
| `--accent-text` | `#ff3a40` | красный мелкий текст | 5.8:1 |
| `--line` / `--line-2` / `--line-3` | off-white 9 / 16 / 30% | разделители | декоративные |
| `--line-ui` | off-white 42% | границы полей и чекбоксов | ≥3:1 (1.4.11) |

Запрещено: синий, фиолетовый, циан, зелёный, оранжевый, RGB-неон, «Apple white».
Фото показываются в естественных цветах (см. «Изображения»).

## 2. Типографика
- **Display:** FuturisC — фирменный шрифт globaleffects.ru, тот же файл, что отдаёт действующий сайт (`/fonts/FuturisC.woff`). Одно начертание Regular. Заголовки, меню, названия товаров, цены и все подписи ПРОПИСНЫМИ. В правилах стоит `font-weight: 300`: при этом весе запасной Jost (знаки ₽ · → ×, которых в файле нет) совпадает с ним по толщине штриха.
- **Body:** HelveticaNeueCyr — Roman для текста, Bold для кнопок и акцентов (`/fonts/HelveticaNeueCyr-Roman.woff`, `-Bold.woff`). Запасной — Onest.
- Метрики обоих шрифтов в `@font-face` приведены к прежним (Jost, Onest): базовые линии и высота строк не меняются.
- Шкала (fluid clamp): hero 3→8.75rem · display 2.2→5.75 · h1 1.9→4 · h2 1.6→2.9 · h3 1.2→1.65 · lead 1.05→1.3 · body 1rem · sm .875 · xs .75 (минимум 12px, только метки).
- Цифры цен и счётчиков — `tabular-nums`.
- Подпись раздела (eyebrow): красная риска 32×2 + uppercase xs, tracking .14em.
- Маркер главы: «Эффекты — 02 / 07», номер красным. Общий rail глав на ≥1440px.

## 3. Сетка и отступы
4pt-шкала `--s-1…--s-10` (4 → 128px). Секции: `--section-y` clamp(88→176px).
Контейнер 1520px, gutter clamp(16→56px). Брейкпоинты: 560 / 768 / 900 / 1024 / 1100 / 1280 / 1440.

## 4. Радиусы и поверхности
Индустриальная точность: `2 / 4 / 6px`. Pill — только для бейджа корзины.
Карточки — не «плашки», а hairline-матрица (`gap: 1px` по `--line`), студийные фото товаров лежат прямо на чёрном.

## 5. Кнопки
| Вариант | Вид | Когда |
|---|---|---|
| Primary | красное тело + отдельный светлый блок стрелки; при hover стрелка «проезжает», тело расширяется | одно главное действие на экран |
| Secondary | hairline-обводка, иконка в отдельной ячейке | вторые действия |
| Ghost | текст + линия, красная линия растёт при hover, красная стрелка | навигационные ссылки |
Размеры: lg 58 · md 48 · sm 40px; цели касания ≥44px.

## 6. Motion system
| Уровень | Длительность | Где |
|---|---|---|
| micro | 180ms | hover, press, переключатели |
| ui | 340ms (выход 220ms) | меню, drawer, диалоги, тосты |
| content | 760ms | reveal, crossfade |
| cine | 1250ms | смена сцен, hero, маски заголовков |

Easing: `--ease-out` cubic-bezier(.16,1,.3,1) на появление, `--ease-in` на уход, `--ease-in-out` на перемещения.

Паттерны (их ровно пять):
1. **Reveal** — fade + подъём 28px, stagger 45ms (`[data-reveal]`, `[data-reveal-group]`).
2. **Mask** — строки заголовков выезжают из-под маски (`[data-reveal="mask"] .line`).
3. **Scene** — sticky-секция, rAF пишет `--p` (0…1), CSS превращает это в transform/opacity (hero-переход, дрейф фото).
4. **Rail** — горизонтальная лента с нативной прокруткой и стрелками (товары, «Как рождается эффект»). Вертикальный скролл её не двигает.
5. **Micro** — стрелки, подчёркивания, зум изображений 1.04, bump бейджа.

`prefers-reduced-motion: reduce`: сцены не закрепляются, видео и автоповорот кадров отключены, reveal — сразу в финальном состоянии.

## 7. Изображения
- Кинематографичные сцены (hero, эффекты, CTA): настоящие фото и кадры видео в естественных цветах (`tools/scenes.py`). Затемняются только CSS-градиентом там, где поверх лежит текст.
- Галерея и превью видео: оригинал в естественных цветах, без фильтров.
- Товары: оригинальные студийные кадры на чёрном (родной стиль бренда).
- Все `<img>` с `width`/`height` (CLS), ниже первого экрана — `loading="lazy"`.

## 8. Доступность (проверено)
Skip-link, landmarks, один h1 на страницу, иерархия заголовков без пропусков, видимый фокус (белый 2px),
нативные `<dialog>` (фокус, Esc, inert-фон), combobox/listbox в поиске, tabs со стрелками, живые регионы для корзины и фильтров,
наличие передаётся текстом и формой, а не только цветом, пауза для автосмены кадров hero.

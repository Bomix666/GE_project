# tools/ — снимок контента с globaleffects.ru

Разовые утилиты, которыми собраны `public/data/*` и `public/media/*`.
Они **только читают** публичные страницы сайта; на backend ничего не отправляется.

| Скрипт | Что делает | Результат |
|---|---|---|
| `01_scrape_categories.py` | Обходит 17 реальных категорий с пагинацией, собирает id/slug/название/цену (со скидкой и без)/наличие/фильтры | `cats_full.json` |
| `02_scrape_products.py` | Скачивает страницы всех товаров (316), 4 потока, пауза 0.3 с | `prods/*.html` |
| `03_build_catalog.py` | Разбирает товары: цена и цена без скидки, наличие (`В корзину` / `Под заказ` / без цены), характеристики, файлы, галерея, «Рекомендуемые товары», очищенное описание | `catalog.json` |
| `04_compare_live.py` | Сверка перед передачей: сравнивает свежий `cats_full.json` со снимком в `public/data` (состав категорий, названия, цены и скидки, наличие, фото) и печатает отчёт. Ничего не записывает | отчёт в консоли |
| `05_compare_picker.py` | Сверка подбора: спрашивает у фильтра сайта, какие конфетти-машины подходят под каждый ответ квиза, и сравнивает с `specs` в снимке. Ничего не записывает | отчёт в консоли |
| `scenes.py` | Собирает крупные сцены (первый экран, эффекты, «О компании», CTA) из фото галереи и кадров видео в естественных цветах, экспорт WebP | `public/media/scenes/*.webp` |

Запуск идёт из временной папки: скрипты пишут рядом с собой. После сборки
`catalog.json` разложен на `public/data/catalog.json` (индекс для листингов и поиска)
и `public/data/products/<slug>.json` (карточки).

Скрипты нужны только для снимка. Сами данные в этом формате нужны и в production:
каталог, карточки товаров, новости, блог и галерею страницы редизайна строят в браузере
из JSON. На сайте эти файлы (или ответы по тем же адресам) формирует backend из
существующей базы, то есть выгрузка из её моделей. Формат полей и варианты подключения
описаны в [`docs/BACKEND-HANDOFF.md`](../docs/BACKEND-HANDOFF.md), раздел 4.

# tools/ — снимок контента с globaleffects.ru

Разовые утилиты, которыми собраны `public/data/*` и `public/media/*`.
Они **только читают** публичные страницы сайта; на backend ничего не отправляется.

| Скрипт | Что делает | Результат |
|---|---|---|
| `01_scrape_categories.py` | Обходит 17 реальных категорий с пагинацией, собирает id/slug/название/цену/наличие/фильтры | `cats_full.json` |
| `02_scrape_products.py` | Скачивает страницы всех товаров (316), 4 потока, пауза 0.3 с | `prods/*.html` |
| `03_build_catalog.py` | Разбирает товары: цена, наличие (`В корзину` / `Под заказ` / без цены), характеристики, файлы, галерея, «Рекомендуемые товары», очищенное описание | `catalog.json` |
| `grade.py` | Тонирование фото в фирменный чёрно-красный (трёхтоновая LUT + 22% исходного цвета), экспорт WebP | `public/media/scenes/*.webp` |

Запуск идёт из временной папки: скрипты пишут рядом с собой. После сборки
`catalog.json` разложен на `public/data/catalog.json` (индекс для листингов и поиска)
и `public/data/products/<slug>.json` (карточки).

В production эти файлы не нужны: те же данные выводят существующие Yii-шаблоны.
Единственный вариант оставить JSON — статический индекс для мгновенного поиска,
который можно генерировать при деплое без изменения API.
